# 🐍 Phase 00 — Python Foundations

**Status:** 🟡 In Progress

## 🎯 Goal

Build a Python base strong enough to understand Pydantic, PydanticAI and modern AI application development.

> 💡 Pydantic is *built on* type hints and decorators. Every hour spent here saves three later.

## 📂 What lives in this folder

| Path | Contents |
|---|---|
| `notes/` | One markdown file per topic, using the notes template |
| `examples/` | Minimal working code — typed from memory, not copy-pasted |
| `practice/` | Deliberately broken code + the fix, and mini experiments |
